# Biosphere
Jeu de plateau Biosphere en Java

Le projet Biosphère est un projet de programmation découpé en deux phases : Lors de la première phase, nous devions programmer les règles d’un jeu. Lors de la seconde phase, nous devons coder une IA qui devait jouer au jeu le plus parfaitement possible. Ce projet m’a avant tout permis de mieux comprendre la notion de classe en Java. J’ai aussi appris à coder avec des fichiers, des fonctions et des variables déjà implémentées.
